# truenas-notes

Личный репозиторий с заметками, конфигурациями и вспомогательными
скриптами для TrueNAS.

## Структура

Каждый материал лежит в отдельной директории или отдельном файле
с понятным именем. Со временем репозиторий будет пополняться.

## Использование

Все материалы предоставляются «как есть». Перед применением
чего-либо на продакшн-системе рекомендуется:

1. Сделать бэкап конфигурации TrueNAS
   (**System Settings → General → Save Config**).
2. Проверить команды и скрипты в тестовой среде.
3. Убедиться, что вы понимаете, что делает каждая команда.

## Требования

- TrueNAS SCALE (версии могут отличаться в деталях).
- Доступ к Shell с правами root для большинства операций.
- Базовое знакомство с ZFS, `midclt` и системой приложений TrueNAS.
